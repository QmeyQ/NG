# NG · Badminton3D

一个小游戏平台：LayaAir 3.3.1 + TypeScript，微信小游戏与 Web 双端共用一套源码。平台层负责启动、账号、资源分包、选局与匹配，首个完整玩法是羽毛球 3D（PVE 单机 / PVP 实时对战）。

[![NG 项目规划](https://qmeyq.github.io/NG/preview.png)](https://qmeyq.github.io/NG/node-workflow.html)

## 平台层

- **启动与隐私**：启动页 → 隐私协议 → 资源版本检查 → 下载/恢复 → 主菜单
- **主菜单与选局**：首页 / 商店 / 社交 / 我的 / 设置 五页；游戏大厅当前仅羽毛球开放，其余条目占位
- **账号与云服务**：Cloud 用户体系 + AGC 云函数（注册 / 登录 / 改名 / 头像 / 购买 / 背包），Cloudflare Worker 网关统一入口并下发联机凭据
- **资源与存储**：nor / ui / game 三级分包，版本比对、下载解压与进度预测，Web 走 IndexedDB、微信走本地缓存
- **匹配与联机**：华为 GOBE 实时房间，随机匹配、进房角色指派、断线重连与旧会话恢复
- **平台适配**：微信 / Web 差异收敛在一处（存储、文件、网络、音频解锁、场景导航）

## 羽毛球玩法

- **赛制**：21 分净胜 2 分、30 分封顶、三局两胜；发球权与接发轮换、站位与发球区校验、越界与落地结算、局间换边
- **模式**：单打 / 双打；PVE 四档难度 AI（落点预测 + PID 自纠错 + 双打分工），PVP 1v1 / 2v2 实时对战
- **操作**：摇杆移动，按住蓄力、滑动定向；单手与双手两套击球角度映射，含特殊击球
- **鹰眼**：落地轨迹记录与回放，挑战确认两端同步进入
- **球同步**：球是绝对时间驱动的定点物理（Q10 定点 + RK4），只同步击球参数与入口时刻，两端各自积分结果一致；角色走帧通道，事件与比分走可靠通道

## 技术栈

- **客户端**：LayaAir 3.3.1 / TypeScript，单 bundle 产出；比赛侧按 物理内核 / 规则 / 管理 / 网络 / 对象 / 输入 / AI 分层
- **服务端**：Cloudflare Worker 网关 + 自实现 AGC 代理 SDK + AGC 云函数与 CloudDB
- **联机**：华为 GOBE（帧同步房间 + 可靠消息双通道），权威端选举与任期交接
