# 龙骨本地播放器（DragonBones 本地预览页）

用开源 **DragonBonesJS（master 分支，5.7.0）** 源码在这台机器上现场编译出运行时，配合 PixiJS 4.6.2 拼成的**纯本地、离线、免费**的龙骨动画播放页。

## 一句话结论

- ✅ 能做：**本地预览/播放龙骨动画**（DragonBones 5.x 导出的骨架 + 图集）。
- ❌ 不能做：**网页版龙骨编辑器**——DragonBones Pro 是 AIR 桌面程序，继任者 LoongBones 闭源，开源仓库只发布"运行时"。

## 怎么打开

双击本目录下的 **`启动.bat`**：它会用 Python 起一个本地 HTTP 服务（127.0.0.1:8123）并自动打开浏览器。

> 必须走 HTTP，不能直接双击 `web/index.html`——`file://` 协议下浏览器会拦截 XHR，读不到骨架 JSON。

手动方式（任意终端）：

```bat
cd /d F:\work\dragonbones-local-web\web
python -m http.server 8123 --bind 127.0.0.1
```

然后浏览器打开 <http://127.0.0.1:8123/>

## 页面能做什么

- 左侧内置两个示例（点一下即加载）：`机甲 1004d`（标准 JSON）、`机甲 1406`（二进制 `.dbbin`）
- 拖入自己的龙骨文件，或点"选择文件 / 选择文件夹"
- 识别方式：读 JSON 内容判断，**不依赖文件名**
  - 骨架：含 `armature` 字段的 `*_ske.json` / `*.skel`，或 `*_ske.dbbin`（二进制）
  - 图集：含 `SubTexture` 字段的 `*_tex.json`
  - 贴图：`.png / .jpg / .webp`
  - 多张图集的资源也支持（按文件名前缀配对图片）
- 底部控制条：切换骨架、切换动画、暂停/播放、循环开关、速度（0.05×–3×）、缩放（0.3×–4×）、适配窗口、实时 FPS
- 左侧"当前资源"显示来源、骨架名、动画数量、贴图尺寸、当前缩放

## 运行时是怎么来的（可复现）

```bat
:: 1. 取源码
curl -L -o "%TEMP%\dragonbonesjs-master.zip" https://codeload.github.com/DragonBones/DragonBonesJS/zip/refs/heads/master
:: 2. 装构建依赖
cd /d F:\work\dragonbones-local-web\DragonBonesJS-master
npm install
:: 3. 生成 PixiJS 4.6.2 适配版运行时
node builds\cli.js pixijs@4.6.2 -o F:\work\dragonbones-local-web\runtime
```

输出即 `runtime\dragonBones.js`（749,349 字节）+ `dragonBones.d.ts`（250,074 字节）。
官方 CLI 的用法是 `dbr <引擎>@<版本>`（`egret / pixijs / phaser / phaser-ce / hilo`），输出到 `dragonbones-out`，`-o` 可改目录。

> 注意：npm 上的 `dragonbones-runtime` 最新只到 **5.6.200**（2018 年），想要 master 的 5.7.0 必须像上面这样本地 clone + 构建。

## 换引擎 / 升级

- 想用 PixiJS 8.x：把 `web\libs\pixi.js` 换成 PixiJS 8 的 UMD 包，并用 `node builds\cli.js pixijs@8.x.x -o ...` 重编运行时（仓库里 `Pixi\8.x` 有对应源码与预编译产物可对照）。
- 想用 Egret/Hilo/Phaser：同一套 CLI 换引擎名即可，但页面里的 Pixi 渲染部分要跟着重写（本页只做了 PixiJS 版本）。

## 已知限制（这一版没做）

- 只做了**播放/预览**：没有骨骼拖动、换装、事件时间轴、导出等编辑器功能。
- 动画事件（音效/自定义事件）只解析不回调；如需要可在 `app.js` 里监听 `display.addEventListener(dragonBones.EventObject.SOUND_EVENT, ...)`。
- 骨架用的是数据自带缩放；没有做 DPI/多分辨率图集切换。
