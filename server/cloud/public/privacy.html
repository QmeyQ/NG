一、引言

肖文健（以下简称"我们"）是典游（以下简称"本游戏"）的开发者与运营者。我们深知个人信息对您的重要性，并会尽全力保护您的个人信息安全可靠。我们致力于维持您对我们的信任，恪守以下原则：只收集为您提供游戏服务所必需的信息；未经您的同意，不收集、不使用、不对外提供与游戏服务无关的个人信息。

请在使用本游戏前，仔细阅读并充分理解本政策全部内容，特别是免除或限制责任的条款、争议解决条款等。一旦您勾选"同意"并进入游戏，即表示您已阅读并同意受本政策约束。若您不同意本政策，请选择"拒绝"退出游戏；选择"拒绝"后我们不会收集您的个人信息。

本政策适用于您通过浏览器访问本游戏（域名为 normalgame.cn）时我们对您个人信息的处理。

二、我们收集的信息

我们仅收集以下与提供游戏服务直接相关的信息。我们不会收集您的姓名、电话、证件号码、通讯录、位置信息、相机、麦克风权限下产生的信息，也不会读取您设备中的其他应用数据。

2.5 本地存储的信息

以下信息存储在您自己的浏览器本地（IndexedDB 与 localStorage），不会上传至服务器，您可以随时通过浏览器的"清除浏览数据"功能删除：

  • 您的用户ID、登录密匙与个人资料（用于自动登录，避免每次重复输入）；
  • 已下载的游戏资源包缓存（用于加快资源加载，避免重复下载）；
  • 您对本隐私政策的同意状态（用于记录您是否已同意）。

三、信息的使用

我们仅将收集的信息用于以下目的：

  1. 账号注册、登录验证与身份识别；
  2. 保存与恢复您的游戏进度、虚拟资产与对局记录；
  3. 在游戏内向其他玩家展示您的昵称、头像与签名；
  4. 联机对战中的房间匹配、断线判断与成绩统计；
  5. 访问频率控制与恶意请求拦截，保障服务安全稳定。

我们不会将您的个人信息用于本政策未载明的其他目的；如需变更使用目的，我们将再次征得您的同意。

四、信息的存储与保存期限

  • 存储地点：您的账号数据存储于华为云 CloudDB 数据库（数据处理位置：中国大陆）；游戏资源存储于华为云云存储并通过 CDN 分发。
  • 保存期限：您的个人信息将在您的账号存续期间保存。当您注销账号（见第六章）后，服务器上与该账号相关的全部个人信息（用户ID、昵称、签名、头像、金币、背包、对局记录、登录密匙）将被立即删除且不可恢复。
  • 风控数据：用于访问频率限制的IP地址记录仅在内存中短时保存，最长不超过封禁时长，过期自动失效，不作长期存储。
  • 本地数据：存储在您浏览器本地的数据（见 2.5 节）持续保存至您主动清除浏览器数据或注销账号时由游戏协助清除。

六、您的权利

您对自己的个人信息享有以下权利。除游戏内已有的自助功能外，您也可以通过第十章的联系方式联系我们，我们将在15个工作日内响应。

  • 查询与访问：在游戏内的个人页面中，您可随时查看自己的昵称、签名、头像、金币与背包。
  • 更正与修改：在游戏内的设置中，您可随时修改昵称与签名、更换头像。
  • 删除与账号注销：在游戏内进入"游戏选择→设置"，点击"清除数据"并确认，即可注销账号。注销后服务器上与该账号相关的全部个人信息将被立即删除且不可恢复。您也可联系我们协助注销。
  • 撤回同意：您可以通过注销账号的方式撤回此前对个人信息处理的同意；撤回同意后，我们将停止处理您的个人信息并删除服务器上的相关数据。撤回同意不影响撤回前基于您的同意已进行的个人信息处理。
  • 本地数据清除：您可随时通过浏览器的"清除浏览数据"功能删除存储在本地的登录凭据与资源缓存。
提示：注销账号会删除您的全部游戏进度与虚拟资产，且不可恢复，请在操作前确认。

七、未成年人保护

我们非常重视对未成年人个人信息的保护。本游戏不面向不满十四周岁的未成年人，我们不会主动收集未成年人的个人信息。若您是未成年人的监护人，发现您监护的未成年人使用本游戏并提供了个人信息，请通过第十章的联系方式联系我们，我们将在核实后尽快删除相关信息。

我们鼓励监护人指导未成年人正确、安全地使用网络产品与服务，合理安排游戏时间，避免沉迷。

八、信息安全

我们采取以下措施保护您的信息安全：

  • 登录密匙在注册时经加密处理后下发与存储，后续请求通过密匙校验防止账号被冒用；
  • 游戏与服务器之间的通信全程使用 HTTPS 加密传输；
  • 服务器侧实施访问频率限制与IP封禁机制，防御恶意攻击与滥用；
  • 云数据库仅可通过经过身份验证的云函数访问，不对外开放直连。

但请您理解，由于技术限制及可能存在的各种恶意手段，在互联网环境下不存在绝对的信息安全。如不幸发生个人信息安全事件，我们将及时通知您并采取补救措施。

九、隐私政策的修订

我们可能适时对本政策进行修订。当政策的条款发生重大变更时，我们会通过在本游戏启动时弹窗提示等显著方式通知您。若您在政策修订后继续使用本游戏，即表示您已充分阅读、理解并接受修订后的政策；若您不同意修订后的内容，您可停止使用本游戏并注销账号。
